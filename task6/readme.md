# Задание 6

rag_bot_yandexGPT_defended.py - бот, который взят из задания 5

update_index.py - скрипт автоматического обновления индекса chromaDB, в скрипт включено расписание 1 раз в день (в 6 утра), в качестве альтернативы рассматривался cron, но в docker-контейнере с ним возникли проблемы, решено сделать через schedule python

dockerfile.bot - контейнер с rag-ботом

dockerfile.updater - контейнер с процессом обновления индекса

docker-compose.yml - описатель приложения с запуском бота и апдейтера, как отдельных сервисов

new_docs - каталог с новыми документами, которые должны автоматически подхватиться в индекс

data - каталог для логов и json-файл для индексации файлов, чтобы можно было определять difference, и добавлять в индекс только свежие файлы

architecture - каталог с puml-диаграммой, объясняющей логику работы автоматического обновления индекса

Для запуска необходимо в task6 добавить .env-файл, в котором указать ключи API и директории для доступа к yandexGPT в формате:
YC_API_KEY=***
YC_FOLDER_ID=***

## Запуск
Стандартный запуск:
```bash
docker-compose up -d --build
```
Для локального тестирования бота:
```bash
 docker-compose run --rm rag-bot
```

Для тестирования можно уменьшить период обновления - расписание (раскомментировать соответствующую строку 155 в update_index.py)

Ответ:
**Шаги рассуждений:**

1. В предоставленных документах есть информация о dark side artifact.
