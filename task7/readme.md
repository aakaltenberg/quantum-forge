# Задание 7
autotests.py - скрипт для автоматической проверки качества работы rag-бота на примере набора "золотых вопросов"
golden_questions.json - набор золотых вопросов для проверки бота
autotests_report_before_delete_info_from_index.json - отчет, сформированный скриптом autotests.py до удаления чанков из chromaDB
autotests_report_after_delete.json - отчет, сформированный скриптом autotests.py после удаления чанков из chromaDB
delete_chunks_by_sources.py - скрипт для удаления чанков из chromaDB по захардкоженному списку ресурсов
logs.jsonl - логи выполнения запросов

## Результаты
Видно, что в отчете до удаления чанков ответы на все "золотые" вопросы получены успешно, при этом после удаления части чанков, связанных с определенными ресурсами, наблюдается отсутствие ответа на один из вопросов:
```json  
  {
    "question": "Кто создал dark side artifact?",
    "expected": "ANSWER",
    "success": false,
    "answer_preview": "В предоставленных документах нет информации о том, кто создал dark side artifact.\n\nОтвет: Я не знаю."
  }
```

Таким образом, "базовые" проверки общих тем данный скрипт, подготовленный для автотестирования, может помочь осуществить, при этом для оценки полноты базы знаний, ее точности, необходимо очень сильно расширять набор "золотых" вопросов, по которым можно будет давать более глубокую оценку качества rag-бота.
